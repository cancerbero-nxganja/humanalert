# HumanAlert — 使命宣言

## 三大真理

**作为一个物种，我们只有彼此。**  
在危机中，第一个响应者永远是邻居。HumanAlert 将协调工具放入每个人的口袋。

**地球是我们的家园。**  
我们假设基础设施可能会失败来构建系统。所有功能在 2G 网络上运行。我们选择 OpenStreetMap，因为世界地图属于全世界。

**动物是自由的生命。**  
走失的宠物、流离失所的野生动物无法呼救。HumanAlert 与 PetWhisper / AlertaMascota 生态系统集成，为它们发声。此集成永久免费，无一例外。

---

## 我们构建什么

HumanAlert 是一个人道主义紧急协调平台：警报、失踪人员、动物、社区资源。一切离线可用。一切尊重隐私。无广告。不变现数据。

---

## 我们的承诺

- **永久开源**
- **100%捐赠** — 所有收入用于人道主义事业
- **质量不妥协** — 70%+测试覆盖率、WCAG 2.1 AA、8种语言
- **隐私优先设计** — 从不存储全名、从不存储照片、从不要求个人数据
