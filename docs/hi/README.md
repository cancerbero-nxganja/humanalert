# HumanAlert — संस्थाओं के लिए त्वरित प्रारंभ मार्गदर्शिका

> **5 मिनट में आपका पहला अलर्ट।**

HumanAlert ओपन सोर्स है, हमेशा मुफ़्त है, और सभी आय का 100% मानवीय उद्देश्यों के लिए दान किया जाता है।

---

## पूर्व-आवश्यकताएं

| आवश्यकता | विवरण |
|---|---|
| कनेक्टिविटी | न्यूनतम 2G / 128 kbps |
| ब्राउज़र | कोई भी आधुनिक ब्राउज़र |
| Admin JWT | आपके HumanAlert सिस्टम प्रशासक द्वारा जारी |

---

## चरण 1 — सेवा सत्यापित करें (30 सेकंड)

```
GET https://<आपका-डोमेन>/api/v1/health
```

अपेक्षित प्रतिक्रिया: `{ "status": "ok" }`

---

## चरण 2 — Admin Token प्राप्त करें (1 मिनट)

HumanAlert प्रशासक से JWT टोकन जनरेट करने का अनुरोध करें। डिफ़ॉल्ट रूप से 24 घंटे में समाप्त होता है।

---

## चरण 3 — पहला अलर्ट भेजें (2 मिनट)

```bash
curl -X POST https://<आपका-डोमेन>/api/v1/alerts \
  -H "Authorization: Bearer <आपका-टोकन>" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "emergency",
    "severity": "high",
    "title": "निकासी सूचना",
    "description": "क्षेत्र A के निवासियों को तुरंत निकलना होगा।",
    "location": { "lat": 28.6139, "lon": 77.2090 },
    "radius_km": 5,
    "language": "hi"
  }'
```

---

## चरण 4 — लापता व्यक्ति की रिपोर्ट करें (1 मिनट)

`POST /api/v1/missing-persons` का उपयोग करें। `amber_alert: true` सेट करने पर AMBER Alert रियल-टाइम में प्रसारित होगा।

---

## चरण 5 — WebSocket के माध्यम से रियल-टाइम अपडेट (30 सेकंड)

```javascript
const ws = new WebSocket('wss://<आपका-डोमेन>/ws');
ws.onmessage = (event) => {
  const { type, data } = JSON.parse(event.data);
  console.log(type, data);
};
```

---

## ऑफलाइन उपयोग

HumanAlert ऐप 2G नेटवर्क पर काम करता है। ऑफलाइन होने पर क्रियाएं `localStorage` में सहेजी जाती हैं और कनेक्टिविटी बहाल होने पर स्वचालित रूप से सिंक होती हैं।
