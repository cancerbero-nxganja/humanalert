# HumanAlert — دليل البدء السريع للمؤسسات

> **5 دقائق لأول تنبيه لك.**

HumanAlert مفتوح المصدر، مجاني للأبد، و100% من الإيرادات تُتبرع بها لأغراض إنسانية.

---

## المتطلبات الأساسية

| المتطلب | التفاصيل |
|---|---|
| الاتصال | 2G / 128 كيلوبت في الثانية كحد أدنى |
| المتصفح | أي متصفح حديث |
| JWT للمسؤول | يُصدر من قبل مسؤول نظام HumanAlert |

---

## الخطوة 1 — التحقق من الخدمة (30 ثانية)

```
GET https://<نطاقك>/api/v1/health
```

الاستجابة المتوقعة: `{ "status": "ok" }`

---

## الخطوة 2 — الحصول على رمز المسؤول (دقيقة واحدة)

اطلب من مسؤول HumanAlert إنشاء رمز JWT. تنتهي صلاحيته بعد 24 ساعة افتراضيًا.

---

## الخطوة 3 — إرسال أول تنبيه (دقيقتان)

```bash
curl -X POST https://<نطاقك>/api/v1/alerts \
  -H "Authorization: Bearer <رمزك>" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "emergency",
    "severity": "high",
    "title": "إشعار إخلاء",
    "description": "يجب على سكان المنطقة أ الإخلاء فورًا.",
    "location": { "lat": 33.5138, "lon": 36.2765 },
    "radius_km": 5,
    "language": "ar"
  }'
```

---

## الخطوة 4 — الإبلاغ عن شخص مفقود (دقيقة واحدة)

استخدم `POST /api/v1/missing-persons` مع `amber_alert: true` لتفعيل تنبيه AMBER في الوقت الفعلي.

---

## الخطوة 5 — التحديثات الفورية عبر WebSocket (30 ثانية)

```javascript
const ws = new WebSocket('wss://<نطاقك>/ws');
ws.onmessage = (event) => {
  const { type, data } = JSON.parse(event.data);
  console.log(type, data);
};
```

---

## الاستخدام دون اتصال

تعمل تطبيقات HumanAlert على شبكات 2G وتخزن الإجراءات في `localStorage` دون اتصال، مع مزامنة تلقائية عند استعادة الاتصال. يدعم واجهة المستخدم اتجاه RTL للغة العربية.
